Research assignment

Build a Python figure for three metrology comparisons. A single plotting default cannot be assumed to work across them. Decide how each axis should encode the scientific question and demonstrate what your choices reveal and conceal.

Measurement definitions

  • Paired potential: twelve independent devices, three fabrication batches, one before and one after observation per device. Instrument resolution is 0.1 mV; no calibration uncertainty is supplied. The question concerns conditioning-induced differences around a roughly 1000 mV operating baseline.
  • Dose response: each row is an independently prepared calibration level, with signal in arbitrary units and supplied expanded uncertainty U, coverage factor k = 2. U describes each reported level, not the spread of raw replicates. No raw replicate values or dose uncertainty are supplied. The question concerns both dynamic range and departures from proportional response.
  • Blank-corrected panel: measured negatives and zero are valid signed estimates after background subtraction. Rows marked left_censored have no numerical point estimate: all that is reported is signal < limit_au. The detection threshold is 0.05 au for every sample. The blank correction can yield negative estimates; missing censored values are not zero. Samples are separate observations; no population distribution is specified.

Work

  1. Write plot.py using Python and local plotting libraries. Generate a main multi-panel figure plus one compact alternative-scale diagnostic. Include enough of the data to evaluate small paired differences, the large dose-response range, and the signed/censored panel.
  2. Write a scale-decision table with one row per axis. State the scientific comparison, chosen mapping and limits, what zero means, and the reason for accepting or rejecting linear, log, offset/zoom, difference, or symlog representations as applicable. Log scaling is a decision to justify; you do not receive credit simply for using it. Do not silently drop, clip, replace or take absolute values of observations to make a transformation work.
  3. Calculate a reproducible summary of paired change that respects device identity. For the calibration plot, preserve the supplied interval definition. Represent censored observations separately from measured values. Any sensitivity calculation involving substituted censored values must be labelled as a sensitivity assumption, with the original records still visible.
  4. Provide an interpretable caption and a brief review at the intended 180 mm figure width. State numerical and inferential limits of these fixtures and your chosen diagnostic.
