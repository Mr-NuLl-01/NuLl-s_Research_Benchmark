# R01 · 参考学习与可编辑科研 SVG

## 任务

为一篇测量方法短文制作一张 **180 mm 宽、三个面板**的原创科研图：读者应能看清实验做了什么、各器件发生了怎样的变化，以及另一组器件的瞬态响应。研究内容是本基准的合成示例，不是真实器件成果。

先打开 `assets/R01/style-references.html`，完整观察 P1 Figure 2、P2 Figure 7 和 P3 Figure 3 及原图注。学习可迁移的视觉决策，不描摹原图，不把三篇文章的内容当作本题实验数据。来源和许可见 `assets/common/SOURCES.md`。

## 给定记录与材料

- `assets/R01/paired.csv`：12 个独立器件，3 个制备批次，每批 4 个；同一器件在 25 °C、10 min 处理前后各测量一次，单位 mV，读数分辨率 0.1 mV。未提供校准不确定度。
- `assets/R01/transient.csv`：独立的瞬态实验，3 批各 2 个独立器件。输入在 0 s 从 0 阶跃到 1 并保持到 12 s；输出是无量纲归一化响应，采样时间不等间隔。这里的器件 ID 是该实验的局部编号，不能与 paired.csv 合并配对。
- 未给出物理机理、统计显著性检验、长期测试或实验之外的数据。

## 完成内容

1. 绘制三个协调的面板：实验与测量关系；所有器件的配对变化；六条瞬态曲线。若加入均值、差值或区间，定义其计算、独立单位及批次关系。保留所有观察值、配对身份、单位与实验区分。
2. 选择能同时表达小变化与约 1000 mV 基线关系的尺度。允许差值、明确标注的局部放大或辅助视图；不因追求视觉冲击隐去轴范围，也不强制某一种图型。
3. 写 250–400 个英文词的 `design-note.md`，分别指出三张参考中一个具体可见的设计选择、你采用或放弃的部分及原因。不能仅列“配色简洁、字体统一”等通用口号。
4. 写 140–220 个英文词的 `caption.md`，说明合成性质、面板、样本单位、批次及实际显示的统计量；不能凭示意箭头增加因果机理。
5. 输出 live text SVG，数据、文字和科学元素须能分别编辑。制作 PNG 预览，在 180 mm 宽下检查文字和符号（目标正文标签至少约 7 pt），并记录发现的问题、实际检查方法和未检查部分。

## 交付

`figure.svg`、`figure.png`、`caption.md`、`design-note.md`、`source.zip`、`review.md`。

`source.zip` 包含自然可编辑源文件或再生成代码、数据与最短本地操作说明；不能只压入最终 PNG。允许使用本地工具与库，禁止外部图片、字体下载、其他模型答案或未提供论文。不会因为采用某一绘图工具加分。

## 评分重点

|维度|分值|
|---|---:|
|科学编码、数据、配对和独立单位|30|
|对三幅实际参考的具体学习与合理改造|20|
|尺度、比较与不确定度判断|20|
|布局、可读性与视觉身份|15|
|可编辑交付、图注与实际检查|15|

科学数据被实质改变或捏造时总分上限 40；未交可打开的矢量成果时上限 35；完全未分析给定三张参考时上限 70。是否触发以实际材料和明确证据判断，无法观察的项目保持待评，不能推断为通过。
