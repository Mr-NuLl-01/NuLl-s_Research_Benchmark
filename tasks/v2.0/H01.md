# H01 · 聊天端单 HTML 科研工作台

## 任务

在聊天中交付一个可保存并直接离线打开的 **`workbench.html`**。实验研究者应能从数据概览进入某个样本的详情、返回原筛选状态、探索尺度并导出当前数据。只需要一个 HTML，不依赖服务器、CDN、外部字体、网络请求或额外资源文件。

页面通过布局表达操作顺序。避免重复次级标签和长解释段；必要科学定义放在轴标签、图例或紧邻的数据说明中。美观不能替代真实交互。

## 输入数据

把以下三个 CSV 的完整原始数据嵌入 HTML，而不是联网读取：

- `assets/H01/paired.csv`：12 个独立器件，3 批各 4 个，一次处理前后配对；单位 mV，分辨率 0.1 mV，无校准不确定度。不要把两次测量当两个独立器件。
- `assets/H01/dose_response.csv`：独立校准水平，信号区间为扩展不确定度 U，覆盖因子 k=2；无原始重复值或剂量误差。
- `assets/H01/blank_corrected.csv`：负数和零是合法扣背景结果；删失记录的值为空，仅知低于 0.05 au。空值不能转为零、NaN 或阈值点估计。

数据为合成夹具。除非原文明确说明，没有总体统计或因果结论。

## 必须能完成的工作

1. **浏览与筛选。** 展示三组数据；对配对器件提供批次筛选和 ID 搜索（搜索忽略大小写并去掉前后空格，匹配完整 ID 的子串，和批次筛选取交集）。视图、样本数及均值/配对变化摘要随筛选一致更新。没有匹配项时显示真实空态，摘要显示不可计算，不残留上一组数值。
2. **详情与返回。** 选中器件可查看 before / after / difference、批次和单位。提供明确返回操作；返回后保留搜索、筛选和比较模式。详情内容必须属于当前选中 ID，不能只显示固定示例。切换筛选时不保留已被排除器件的陈旧详情。
3. **比较与尺度。** 配对面板至少提供原始 before/after 与差值两种视图。剂量响应提供合适的线性与对数尺度切换；区间和计数随图同步。对 signed/censored 数据保持负值、零、实测和删失的区别，不允许一个不适用的 log 开关悄悄丢点。
4. **导出与恢复。** 导出当前筛选后的配对原始记录为 CSV，字段顺序为 `device,batch,before_mV,after_mV`；没有匹配项时应禁用导出并在本地说明原因，或导出只有表头的合法 CSV。两种行为均接受。另提供 JSON 状态导出/导入，包含 schema、批次、搜索和比较模式。导入非法 JSON、未知 schema、未知批次或非法模式时显示可理解错误，且原状态和数据不得被部分覆盖。有效导入后完整恢复视图。重置恢复初始无筛选状态。
5. **可访问与离线。** 关键控件可键盘操作、有可读名称；提供原始数据表或等价文本访问，不能只依赖颜色或 hover。在桌面 1280 px 和窄屏 390 px 宽下可用，避免正文横向溢出。允许数据表局部滚动。浏览器刷新不强制要求持久化，若实现需说明。

状态 JSON 的精确字段可自行设计，但 `schema` 必须为 `nrb-h01-state-v1`，导入/导出互通。不得把导出的状态当作科学数据替代品。

## 交付

- `workbench.html`，作为真实附件或完整可保存源码。单张效果图不算实现。
- `verification.md`：不超过 700 英文词或 1100 汉字；列出实际操作、观察结果、浏览器/尺寸和未测试部分。若聊天环境无浏览器，明确区分源码检查与实测，仍交付 HTML；不因此编造交互成功。

验证者会用实际控件运行正常、空结果、返回、重置、有效/无效导入和下载流程，并核对导出 CSV 字节对应可见筛选。只出现按钮但不更新数据不能得功能分。

## 评分重点

|维度|分值|
|---|---:|
|数据、尺度、符号/删失与不确定度语义|25|
|筛选、详情返回及状态一致性|30|
|离线运行、真实导出和原子导入|20|
|布局、响应式与可访问性|15|
|实际验证记录与诚实的边界|10|

无实际 HTML 或不能离线使用时上限 35；核心操作仅为静态装饰时上限 40；实质篡改配对/符号/删失含义时上限 45；导出数据与筛选状态不符或非法导入破坏状态时上限 60。评分来自实际操作和证据，不能把候选自述当成已测结果。
