# R02 · 小差异、宽动态范围与删失数据绘图

## 任务与输入

写 Python 绘图程序，为三个测量问题制作协调的多面板图，并用一张紧凑的替代尺度诊断图说明主要选择的得失。数据均为原创合成夹具。

|文件|数据语义与科学问题|
|---|---|
|`assets/R02/paired.csv`|12 个独立器件、3 批、每批 4 个；同一器件处理前后各一次测量。约 1000 mV 基线上存在小的配对变化；读数分辨率 0.1 mV，校准不确定度未知。|
|`assets/R02/dose_response.csv`|每行是独立配制的校准水平；`expanded_uncertainty_au` 是该水平信号的扩展不确定度 U，覆盖因子 k=2，不是原始重复样本 SD。无剂量不确定度或原始重复。需要同时看动态范围及偏离正比例响应。|
|`assets/R02/blank_corrected.csv`|负值和零是合法的扣背景测量；`left_censored` 行没有点估计，只知信号小于 `limit_au`。所有阈值为 0.05 au；空白不是零，也不等于阈值的一半。|

## 完成内容

- `plot.py` 从这些 CSV 读取数据，产生主图 `figure.svg` / `figure.png`，以及 `alternative-scale.png`。图宽 180 mm。SVG 文字可编辑；不得把重要文字栅格化成整幅截图。
- 保留配对与批次，计算可复现的配对变化摘要到 `summary.csv`。标准差、均值标准误或不确定度不能无说明互换。样本量指器件数，不把前后两次测量算成双倍独立样本。
- 剂量响应同时支持检视跨度和比例偏离；图上区间必须保持 U(k=2) 的含义。可以进行清楚标注的变换，不能创造原始重复值。
- 负值、零、定量正值和删失观察保持可区分。采用 log、symlog、分面、阈值箭头等均须服务科学问题。禁止静默丢弃、取绝对值、裁零或把删失值替换成实测点；若额外给替代值敏感性分析，保留原始记录并明确假设。
- 在 `scale-decisions.md` 中逐轴说明：问题、映射、轴范围、零点含义、区间定义、选择/拒绝其他尺度的理由、180 mm 检查的具体观察。使用 log 本身不加分。
- `caption.md` 为 150–250 个英文词，说明所有面板、合成性质、单位、样本结构及任何辅助诊断的边界。

## 交付

`plot.py`、`requirements.txt`、`figure.svg`、`figure.png`、`alternative-scale.png`、`summary.csv`、`scale-decisions.md`、`caption.md`。提供一条本地再生成命令；仅用已授权本地库，无网络材料或外部模型答案。
