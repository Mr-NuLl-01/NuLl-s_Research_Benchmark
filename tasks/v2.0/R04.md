# R04 · 从图版与原始数据撰写结果和讨论

## 输入

打开 `assets/R04/input-figure.svg` 或 PNG，完整观察 F1a/F1b；同时读取 `paired.csv`、`transient.csv` 和 `experiment-record.md`。它们描述两项独立的合成实验；不要把局部同名器件 ID 跨实验连接。

图版是本题必读输入，不能只基于 CSV 推测图中实际编码。实验记录中的 rough notes 是需要判断的作者草稿，不是已证实结论。图形与数据来自本基准原创夹具，不引用未提供的论文来“补足”机理。

## 完成内容

1. `manuscript.md` 中写两个英文段落：Results 180–260 词，Discussion 200–300 词。Results 明确指向 F1a 与 F1b，至少包含三条对科学判断有用、可从输入复算的定量陈述。不要为凑数量反复报告相同均值。
2. 按器件配对和批次结构做描述性计算。图中均值±SD 是样本离散度，不能改称均值置信区间或校准不确定度。未提供预注册假设或推断检验，不额外凭库函数加入显著性结论。
3. Discussion 解释结果相对于实际基线的量级，区分观察、推断和待验证机理。提出一项能够区分两种具体解释的后续测量，并分别给出预测结果。没有给定的控制、长期可靠性或机理实验不能写成已做。
4. `caption.md`：130–190 英文词，独立定义面板、单位、独立样本、批次身份、图中区间和观察时窗。
5. `claim-evidence.csv`：列 `claim,artifact_location,calculation,status,scope_limit`，status 为 observation / inference / hypothesis / unsupported。覆盖正文关键陈述以及拒绝采用的 rough notes。
6. `calculations.py` 读入给定数据并生成 `calculated-summary.csv`。如选择拟合响应时间，必须说明模型假设、采样分辨能力和可识别性；不拟合不扣分。脚本和输出须支持实际写出的全部数字。

## 交付

`manuscript.md`、`caption.md`、`claim-evidence.csv`、`calculations.py`、`calculated-summary.csv`。只使用给定材料和本地计算库，提供运行命令与版本。

## 评分重点

|维度|分值|
|---|---:|
|实际图版和数据的定量忠实性|30|
|观察、解释、机理与后续判别|25|
|连贯的论文论证和英文|20|
|图注、区间与实验结构|10|
|逐主张证据表与可复现计算|15|

捏造关键数据或把未经观测的机理/长期性能说成确证时上限 40；完全不解释图版的两个面板时上限 60；未提供可追溯计算时上限 65。未实际查看输入图的评阅者不能认证读图维度。
