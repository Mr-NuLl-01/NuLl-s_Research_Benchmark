# P03 — 修复分层导热有限体积求解器

## 科学任务：修复一个有多处独立缺陷的有限体积求解器
求解一维、单位横截面积的分层导热离散模型。每个单元是均匀温度T_i；不是节点边界值。
输入同长列表 dx_m>0（单元宽m）、k_W_mK>0（导热率W/(m K)）、capacity_J_m3K>0（体积热容J/(m³ K)）、initial_K（有限初温K）、source_W_m3（常数体热源W/m³，可负）；另有dt_s>0、整数steps>=0。
left/right 各为 `{"kind":"insulated"}` 或 `{"kind":"fixed","temperature_K":有限数}`。fixed指定单元外表面的温度，不能直接覆盖端单元温度。允许一个单元，此时左右边界作用都需累加。
数学模型定义：M_i=C_i dx_i，内部面导热G_(i,i+1)=2/(dx_i/k_i+dx_(i+1)/k_(i+1))，热流从j进入i为G_ij(T_j-T_i)。固定边界G_b=2k_i/dx_i，流入为G_b(T_b-T_i)；绝热边界流为0。体热源对单元输入S_i dx_i。
采用后向Euler，完整同时求解：
M_i(T_i^(m+1)-T_i^m)/dt=Σ邻面G_ij(T_j^(m+1)-T_i^(m+1))+Σ固定边界G_b(T_b-T_i^(m+1))+S_i dx_i。
输出 `{"temperature_K":[...],"energy_change_J_m2":Σ M_i(T_i^steps-T_i^0),"boundary_energy_J_m2":dt*Σ步Σ固定边界G_b(T_b-T_i^new),"source_energy_J_m2":steps*dt*Σ S_i dx_i}`。总能量单位J/m²，正号表示进入板材。steps=0原样初值且三项能量为0。不得修改输入。
有效规模1..2000单元、0..10000步，测试参数正且有限、量级使三对角系统数值可解。应O(steps*n)时间、O(n)内存，不要用显式时间推进替代此离散模型。非法输入抛ValueError。自动容差温度约1e-9相对、能量约1e-7绝对（小数值另设）。可选说明建议解释错误、界面热阻、单元体积与能量守恒；区分离散模型验证和连续PDE收敛声明。
下面是待修复的完整有缺陷起点；可以重写，可在可选说明中逐类解释缺陷。它不是权威公式，以上离散定义才是规范。
```python
def solve(problem):
    T = problem["initial_K"]
    dx = problem["dx_m"]
    k = problem["k_W_mK"]
    c = problem["capacity_J_m3K"]
    dt = problem["dt_s"]
    for step in range(problem["steps"]):
        for i in range(1, len(T)-1):
            # In-place forward update, arithmetic k, no cell volume.
            T[i] += dt / c[i] * ((k[i]+k[i+1])/2*(T[i+1]-T[i])
                - (k[i-1]+k[i])/2*(T[i]-T[i-1])) / dx[i]**2
        T[0] = problem["left"].get("temperature_K", T[1])
        T[-1] = problem["right"].get("temperature_K", T[-2])
    return {"temperature_K":T,"energy_change_J_m2":0,
            "boundary_energy_J_m2":0,"source_energy_J_m2":0}
```
