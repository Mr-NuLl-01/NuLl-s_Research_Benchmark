# 2026-10-17 评分器修复记录

本次修复基于 `3139c4bf89dac30c3e1d3b5e0e907d4db5183c13`，不修改原十九份候选题面、案例权重或人工量表。以下是评分器和受控参考/错误候选的验证，不是任何模型的能力成绩，也没有模型提供商 API 调用。

## 已修复

1. **物理量整数/浮点误判。** 原通用比较器把参考输出中偶然保留的 `int` 一律当作严格整数字段。现在按字段合同区分实数和计数/步数/随机状态。将同一参考程序的实数输出转换为浮点后，C03 从错误的 60/70 恢复为 70/70，C05 从错误的 13/70 恢复为 70/70；离散字段的浮点替代、布尔值、非有限数和越界数值仍被拒绝。
2. **C06/C08 自报残差未绑定实际输出。** 现在从返回的密度/温度场重新计算原方程、边界、通量和积分。两个回归分别只扰动场值 `1e-8` 并谎报零残差，旧数值匹配会接受，新验证器拒绝。原残差绝对上限保持不变。独立解析正控制和多个种子的参考/制造解均通过。
3. **初始化错误冒充输入异常。** 模块导入失败、缺少 `solve`、不可调用 `solve` 等使用专门初始化错误。正常 `solve` 针对输入抛出的 `ValueError` 仍满足相应异常案例。
4. **重新汇总恢复不可比较分数。** 通用汇总保留输入修改/运行失败资格，拒绝已记录的运行配置冲突，明确显示缺失 provenance。新增多任务回归确保某题生成失败不会使整个汇总崩溃；请求配置与失败时的 `backend=none` 分开处理。`120` 秒和 `120.0` 秒预算等价。

## 未静默改变的范围

- C07 的 257 点粗搜索可能漏掉紧邻端点的内部最小值；当前验收案例没有覆盖该形状。应单独补充端点邻域测试和更可靠的有界搜索，再评估是否调整合同。
