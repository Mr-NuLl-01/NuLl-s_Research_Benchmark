# NRB04–NRB07：数值、计量与数据评测的设计说明

这四题评估能否把明确的科学协议落实为正确计算、可复用代码和可审阅交付。题目使用经典教学问题及程序生成的数据，不引用真实项目、实验记录或未发表研究。每个种子都会改变输入与数值答案；种子不只是题目标题的装饰。

自动分评价提交的数值和可执行行为，人工分评价解释、代码可维护性、证据范围和交付质量。自动判分不通过扫描解释中的关键词来代替科学判断。三个人工维度各 10 分，题包给出 0、5、10 分锚点；中间分数应附具体证据。

这些区分点是设计目标。参考实现和错误变体可以验证评分器能辨认特定错误，但不能证明它已对不同商用模型建立稳定排名。模型区分度、重复运行方差及人工评分者一致性需要另行实测。

## NRB04：先由守恒确定离散量

每个单元宽度为 $h_i$，体积热容为 $c_i$，单元总热容量为 $C_i=c_i h_i$。横截面积设为 1。正通量统一指向坐标增加方向，因此

$$
C_i\frac{u_i^{m+1}-u_i^m}{\Delta t}
=q_{i-1/2}^m-q_{i+1/2}^m+s_i h_i.
$$

两个相邻单元中心之间的半单元热阻串联，给出

$$
q_{i+1/2}=g_{i+1/2}(u_i-u_{i+1}),\qquad
g_{i+1/2}=\left(\frac{h_i}{2k_i}+\frac{h_{i+1}}{2k_{i+1}}\right)^{-1}.
$$

将所有单元方程相加，内部通量成对抵消，得到离散热量守恒。这个恒等式是对离散程序的检查；它本身不证明连续方程误差小。题中显式步长限制来自更新矩阵的非负对角权重：

$$
\Delta t\leq\min_i\frac{C_i}{\sum g_i}.
$$

定通量边界不增加状态相关的出流导纳；定温边界需要计入半单元导纳。只有两个定通量边界的单单元情形没有扩散型步长上限。

评分器用矩阵装配和线性更新生成行为参考；交付的参考代码用面通量循环更新。这两条实现路径没有互相调用。测试另含手算两单元算例、单单元定温边界、热量恒等式，以及把串联热阻误改为算术平均的错误变体。

自动评分结构是可见数值 20 分，加 10 个行为组各 5 分。v0.2 在原有组内扩充至 80 个案例，不增加行为分权重；每组全部案例通过才获该组 5 分，回执的 `cases` 列出每个案例的结果，`detail` 逐项列出失败案例。同一类错误不会因为案例数增加而重复扣分。行为覆盖非均匀网格、导热率跳变、体积热容、源项、不同边界、零步数、单单元及非法输入。只返回可见答案不能获得代码行为分。

v0.2 明确数值输入须为可表示为有限 binary64 值的 Python `int` 或 `float`；布尔值、数值字符串、NaN 和正负 Infinity 均无效。`steps` 必须有 Python `int` 类型，因此 `1.0` 也无效。直接 Python API 的非有限值检查不放宽 JSON 文件格式：评分器通过严格 JSON 传递内部描述符，仅在候选子进程内构造 NaN/Infinity，再调用候选 `solve`。执行器、输入 JSON 的有限性要求以及候选输出的严格 JSON 要求均保留。

新增覆盖包括各类数组的类型、长度、布尔值和非有限值，零/负导热率、零热容、左右边界对象与取值、非法步数和步长，以及单单元的左定温、右定温、双定温情形。双定温单单元必须累加两个半单元导纳，不能因两个边界访问同一单元而覆盖其中一个。步长阈值也直接检查：`dt_bound*(1+1e-12)` 可接受，其下一个更大的 binary64 值拒绝；零步数仍验证稳定性。

## NRB05：把试探状态与已接受状态分开

题目是独立标量/向量测试方程 $y_i'=-\lambda_i y_i$。它不要求发现新的积分方法，而要求准确实现指定策略。v0.2 增加可选的 `t_start`，默认 0，表示 `y0` 所在的绝对初始时间；它必须为有限非布尔数值并满足 `t_start<=t_end`，原来的 `t_end>=0` 条件仍保留。返回历史从 `t_start` 开始，`t_start=t_end` 时不试探。默认输入的初始时间与原行为不变。一个后向欧拉全步与两个后向欧拉半步分别为

$$
y_F=\frac{y}{1+\lambda h},\qquad
y_H=\frac{y}{(1+\lambda h/2)^2}.
$$

小步长展开得到 $y_F-y_H= y\lambda^2h^2/4+O(h^3)$，因此局部差估计使用 $E^{-1/2}$ 调整步长。接受两次半步仍是全局一阶方法；题目禁止用未声明的 Richardson 外推改变返回状态。

分母中的绝对容差、相对容差和尺度下限均在 API 中给定。最大分量决定是否接受。拒绝步保留原时间和状态；最小步长失败、试探预算耗尽及浮点时间停滞有独立状态。最后一个端点截断步可以小于最小步长，但失败后必须终止，不能伪报到达终点。

API 的调度、接受判断和时间运算采用 binary64 浮点语义。`two_half` 通过两次连续除法计算，接受条件为严格定义的 `E<=1`，没有额外的接受容差。评分器独立计算高精度 Decimal 数值状态，同时使用单独的 binary64 状态决定接受、步长和时间推进；它不调用提交的参考源码。这样保留数值状态的独立核对，也不会用 Decimal 时钟制造浮点运算已完成之后的额外端点步。检查比较最终状态、所有提交状态以及试探轨迹，因此“最终数值接近，但拒绝步已污染状态”的实现不能混过行为检查。错误变体特意在拒绝前提交候选状态，以确认评分能识别该缺陷。

此题也是可见结果 20 分、10 个隐藏行为组各 5 分；v0.2 扩充至 78 个组内案例，并逐例报告结果。新增覆盖包括负/非有限衰减率、非法步长上下限、布尔值和非整数试探预算、非法容差与向量形状。计数的整数规则与 NRB04 相同，`max_trials=2.0` 无效。

三个手算接受边界使用 `y0=12`、`rates=2`、`h=1`、`rtol=0`：全步为 4，两半步为 3，`atol=1` 时恰有 `E=1`，必须接受；将 `atol` 改成 1 两侧相邻的 binary64 值，分别得到应接受与应拒绝的情形。另有两个相邻浮点端点控制：`.1+.2` 已到达 `nextafter(.3,+Infinity)` 时不添加额外步骤；从 `.3` 出发尚余一个 ULP 时则确实要完成该极小终步，不能用时间容差提前声称完成。

`t_start` 使时间停滞可由正常 API 输入直接检验，而不改写候选代码。例如 `t_start=1e16`、`t_end=1e16+4`、`h=1` 满足正步长条件，但 binary64 的 `t+h==t`。正确结果为 `time_stalled`、零试探、原始时间与状态；没有停滞检查的错误候选会被组内案例拒绝。正常非零续算和非零零时域案例同时检查 `t_start` 的实际语义。

验证范围是这些生成的有限维测试方程，不代表对任意非线性积分器的认证。binary64 接受决策的算术次序现已在 API 中写明；这是一项 v0.2 答案契约，不应与旧题包的轨迹回执混用。

## NRB06：固定量纲和不确定度模型

题目规定校准参考位移精确，电压标准不确定度独立且绝对已知。v0.2 的校准生成噪声为 `rng.gauss(0.0, sigma)`，标准差直接采用输出 CSV 的 `sigma_mV`，修正此前隐含的 1.4 倍噪声。验证使用随机数接口替身，逐次断言传给 `gauss` 的标准差与对应有效行的 `sigma_mV` 相同；不以某一次样本的约化卡方是否接近 1 作为生成器正确性证据。种子预期值由更新后的公开 CSV 重新计算，不复用旧数据答案。按 $V=a+bx$ 做加权最小二乘，$W_{ii}=1/\sigma_i^2$，因此系数协方差为 $(X^TWX)^{-1}$。这里不从残差估计额外共同方差因子；卡方只作为单独诊断报告。NIST 对加权最小二乘的说明特别区分了逆方差权重及已知权重这一理论前提。[NIST WLS](https://itl.nist.gov/div898/handbook/pmd/section1/pmd143.htm)

逆校准 $x=(V-a)/b$ 的一阶不确定度为

$$
u_x^2=\frac{u_V^2+C_{aa}+x^2C_{bb}+2xC_{ab}}{b^2}.
$$

这里 $u_V^2$ 包括已给定的均值重复性方差和独立显示舍入方差 $q^2/12$。协方差项可能为负，但总方差必须非负。采用一阶传播并保留相关输入项，符合 GUM 第 5 章的传播框架。[GUM 第 5 章](https://www.iso.org/sites/JCGM/GUM/JCGM100/C045315e-html/C045315e_FILES/MAIN_C045315e/05_e.html)

题目要求 $U=2u_x$，并有意称其为 `expanded_k2_mm`。仅知道标准不确定度与扩展因子不足以断言精确覆盖概率；GUM 第 6 章也对这一点作了区分。[GUM 第 6 章](https://www.iso.org/sites/JCGM/GUM/JCGM100/C045315e-html/C045315e_FILES/MAIN_C045315e/06_e.html)

谱数据交替采用 ASD 与 PSD 单位。所有点先转成电压单边 PSD，再对预先指定的分段线性 PSD 和理想通带做精确分段积分。积分结果是方差，开方后才是 RMS；输入等效位移噪声再除以校准斜率的绝对值。ASD 与 PSD 的平方根关系及单边谱约定可核对 SciPy 官方谱分析说明；评分实现只依赖标准库。[SciPy 谱分析](https://docs.scipy.org/doc/scipy/tutorial/signal.html#spectral-analysis)

此题专门使用适合小量的绝对容差。例如 PSD 检查的绝对容差为 $10^{-24}$，不能沿用 $10^{-10}$ 后让全零谱误得分。测试包括手算直线校准、已知协方差、线性谱积分，以及删去协方差或把小量归零的错误答案。

## NRB07：冻结选择并尊重独立样本单位

每个实例生成 36 台机器、3 个机械状态类别及不同数量的重复读数。机器对预测正确率还具有共同的生成效应，因此组内读数不能被当成独立机器。题目给出预先固定的类内分组规则，不让模型根据测试结果挑选更有利划分。`records.csv` 和 `predictions.csv` 顺序不同，必须按 `row_id` 连接。

若目标是对未见机器推广，训练和评估集应在机器组上隔离。这与 scikit-learn 对组相关数据的交叉验证说明一致。[分组交叉验证](https://scikit-learn.org/stable/modules/cross_validation.html#cross-validation-iterators-for-grouped-data)

数据生成器要求出现三项有意构造的差异：验证 macro-F1 的获胜者、验证 accuracy 的获胜者和测试 macro-F1 的获胜者不能混为同一个选择规则。因此直接按整体准确率选型，或事后依据测试成绩选型，都会改变题目答案。`model_a`、`model_b` 中谁应被选定会随种子改变。宏 F1 按固定三类逐类计算后无权平均；空分母置零的规则在题包中明确给定。[F1 官方定义](https://scikit-learn.org/stable/modules/generated/sklearn.metrics.f1_score.html)

Bootstrap 的基本抽样单位是测试机器。每次抽中一台机器，就纳入它的全部读数；同一机器多次抽中必须保留倍数。预先生成的 199 次抽样计划使不同实现无需匹配随机库内部细节。模型在重复抽样中保持冻结，三个类别也保持固定。标准误使用重复统计量的样本标准差，百分位使用题目声明的线性插值定义。

评分参考先合并每台机器的混淆矩阵；测试另用原始读数直接重复展开，独立核对全部 bootstrap 统计量。删除重复抽中的机器、颠倒混淆矩阵方向、将读数数目称为独立机器数，都有对应检查。这里只有 9 台测试机器；百分位区间不是面向实际工业总体的覆盖率保证。

## 执行和证据边界

- NRB04/05 的候选输入文件叫 `starter.py`，保持只读；候选新建 `solution.py`，并把相同源码嵌入 JSON 的 `artifacts`。这样可与输入文件完整性审计同时使用。
- 执行不可用时，代码检查返回“未评”，保留评分覆盖率。缺少所要求的代码则是真实交付失败，不能归为基础设施不可用。
- `trusted` 后端只用于本仓库自有参考代码与已知错误变体。它不是对敌意代码的隔离环境。真实候选执行应使用受支持的隔离后端。
- 所谓隐藏行为输入，是对候选运行工作区隔离；公开仓库中的生成器并非保密题库。发布过的种子和参考答案应作为开发集，正式比较使用未事先发给参测者的种子，并记录版本和题包哈希。
- 本文列出的公式、检查和错误变体不是模型性能测量。运行 `python -m unittest discover -s tests -p test_numerical_tasks.py -v` 可复核原有数值测试；`python -m unittest discover -s tests -p test_v02_numerical.py -v` 核对 v0.2 的分组权重、API、手算边界、随机接口与提交代码负控制。实际模型排名需要运行模型并保留独立评分记录。
- 新增每类拒绝分支都有只违反该类责任的候选负控制：参考计算保持不变，只将对应非法输入的 `ValueError` 错误改为正常返回；评分器必须拒绝该组内案例。另有直接改变单单元导纳、稳定性容差、`E=1` 接受、端点终止、续算初始时间和停滞判断的数值错误实现。测试检查具体失败案例，而不仅检查总分下降。
- NRB04 保留关键检查 ID：`visible_energy_balance`、`insulated_nonuniform`、`flux_source_capacity`。NRB05 保留 `visible_status_and_counts`、`vector_rejection_and_rollback`、`finite_minimum_step_failure`、`failed_clipped_endpoint_is_not_committed`。NRB06 保留协方差与 PSD 相关关键检查及小量拒零控制。新案例不逐个升级成独立关键失败或独立扣分项。
