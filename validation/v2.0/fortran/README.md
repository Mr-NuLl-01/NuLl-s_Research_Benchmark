## 独立关系与判据

F01额外用常D、常v、无源无衰减的解析指数解核对正反漂移及恒定通量，不把同一个三对角求解器的输出重复当作独立依据。

F02参考使用NumPy稠密线性求解，Fortran参考采用Thomas消元；另用两单元2×2闭式解核对一阶推进。评分器从返回的全部轨迹重算通量、源/衰减累计量和归一化每步残差。舍入级残差按公开上限检查，不要求不同合法求解器的残差逐位相同。

F03按输入的原始泊松与连续性方程验收任意满足边界的严格正解，不用某一制造解的坐标作为唯一答案。改变保存的参考坐标不改变正确状态的验收；修改返回势而伪报零残差会被拒绝。

## 执行边界

以上原生运行使用 `trusted`，仅执行本仓库已经审读的参考和故意错误控制程序。未在本机对未知候选执行。隔离评分路径复用既有Docker执行器，容器内只挂载候选源码和运行驱动，不挂载参考输出或评分器。

本机没有Docker daemon，因此本目录不声称Docker执行已经通过；对应CI必须另行实际运行，并以其日志为证。Fortran适配器在Docker候选执行前单独检查编译器，无编译器/容器时返回unavailable而非候选0分；这条分类另有受控故障测试。实际容器编译器版本记录在每次报告中，不能把本机13.3.0当成容器实测版本。

F01公开了二进制64位主元和密度范围，不宣称被拒绝的数值极限在连续模型中无解。F02验证指定离散推进，不把局部代数残差当作连续PDE误差证书。F03限于题面保证存在正解的有界合成族，不提供一般全局唯一性证明。题目设计难度仍未由真实模型统计标定。
